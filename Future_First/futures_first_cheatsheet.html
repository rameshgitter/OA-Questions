Section 1 · Arithmetic & Calculation
Topic 01

Squares & Powers

Formula: a² + b²
Just compute each square and add. e.g. 24² + 42² = 576 + 1764 = 2340
Quick Square Trick (near 50)
n² = (50±d)² = 2500 ± 100d + d²
e.g. 42² = 2500 − 800 + 64 = 1764
Memorize Squares 1–30
Know 1²–20² cold. 21²=441, 25²=625, 30²=900
Topic 02

Percentages

x% of N
Move decimal: 175% of 84 = 1.75 × 84
= 84 + 0.75×84 = 84 + 63 = 147
% of % trick
60% of 10 = 6. So 60%(36/6 + 144/36): simplify inside first → 6+4=10 → 60%×10 = 6
Convert %, fractions fast
75% = 3/4 · 60% = 3/5 · 33.3% = 1/3 · 12.5% = 1/8
Topic 03

Fractions Comparison

Cross Multiply to Compare
a/b vs c/d: compare a×d vs b×c
e.g. 2/3 vs 3/5: 10 vs 9 → 2/3 is larger
Complement trick
11/12, 5/6, 9/10, 6/7 — look at how much is missing from 1:
1/12 < 1/6 < 1/10 < 1/7 → 11/12 is largest
Convert to decimals if stuck
7/11≈0.636, 3/5=0.6, 2/3≈0.667, 4/7≈0.571 → 2/3 is largest
Topic 04

Division & Decimals

Long division shortcuts
72/32 = 9/4 = 2.25. Always simplify fraction first.
Decimal arithmetic
Align decimals. 237.462+352.248: ones place 7+2=9, tenths 4+2=6, hundredths 6+4=10 → carry. = 589.71
BODMAS / Order of ops
Brackets → Division → Mult → Add → Subtract
Never left-to-right blindly with × and ÷
Topic 05

Speed / Rate Problems

Speed = Distance ÷ Time
To find slowest: compute km/hr for each option and compare.
e.g. 30/14.2 ≈ 2.11, 19/9.4 ≈ 2.02, 13/6 ≈ 2.17, 40/19 ≈ 2.11 → 19 km in 9.4 hrs is slowest
Fastest = highest km/hr
Ajay: 13/3 ≈ 4.33 > Dhananjay: 90/14 ≈ 6.43... compare all
Train crossing formula
Relative speed = (l₁+l₂)/time or l₁/time if other is stationary
54 km/h = 15 m/s. 105m in 6s → 105/6=17.5 m/s total → not stationary, same dir
Topic 06

Compound Interest & Investment

CI Formula
A = P(1 + r/n)^(nt)
For annual: A = P(1+r)^t
CI vs SI difference
CI − SI for 2 yrs = P×r²
If SI=40, CI=40.8 → diff=0.8 = P×r² → find r and P
Quarterly compounding
10% quarterly → 10%/4=2.5% per quarter
After 4 quarters: (1.025)^4 ≈ 1.1038 → ~10.38% effective annual rate
Salary comparison trick
Always compute total income over the full period, not just final salary
Topic 07

Profit, Loss & Mixtures

Same selling price → loss formula
If SP is same: SP = CP₁(1−L%) = CP₂(1+G%)
Total CP known → solve for each CP individually
Mixture / Alligation
|(C₁ − M)| : |(C₂ − M)| = ratio of cheaper:dearer
e.g. 40% soda, 16% soda, mix to 24%: |40−24|=16, |16−24|=8 → ratio 1:2 → replaced 1/3
Topic 08

Work, Pipes & Mixtures

Men×Days = constant work
M₁D₁H₁ = M₂D₂H₂
15 men × 21 days × 8 hrs; convert women (3W=2M) → find days for 21 women × 6 hrs
Successive dilution
After n removals: Milk = V×(1 − x/V)^n
80×(1−8/80)³ = 80×(0.9)³ = 80×0.729 = 58.3 L
Section 2 · Logic, Puzzles & Reasoning
Topic 09

Averages & Statistics

Average → Total
Total = Avg × Count. If avg of 3 innings = 16, total = 48. Use to find missing values.
Batting average problem
Let n = number of innings before new score
n×old_avg + new_score = (n+1)×new_avg → solve for n, then next score
Normal distribution
Natural measurements (height, weight) are normally distributed. Registration dates/salaries are skewed.
Topic 10

Probability

P(event) = favourable / total
Square 4cm, circle r=2cm: P(outside circle, inside square)
= (16 − 4π)/16 = 1 − π/4 ≈ 1 − 0.785 = 0.215
Complement rule
P(composite product of 2 dice) = 1 − P(non-composite)
Non-composite products: 1, 2, 3, 5, 7 → count pairs → use complement
Conditional probability
P(kill you | in city) = P(city) × P(target)/targets
Pick city with lowest product of P(presence) × (1/targets)
Topic 11

Counting / Permutations

Alphabetical rank of word
DEMAND: letters A,D,D,E,M,N. Count arrangements starting with letters before D, then before E, etc. Add 1 for the word itself.
Words without DD together
Total arrangements − arrangements with DD together
Then rank DEMAND among valid arrangements only
Topic 12

Logical Deduction / Groups

Constraint satisfaction
List all constraints → test each answer option against ALL constraints. First violation → eliminate. The valid option satisfies every rule.
Common pattern
Condition chains: "A only if B" means B is required whenever A is included. Check both directions.
Topic 13

Pattern / Number Series

Odd one out
Check: digit sum, prime/composite, digit pattern, differences between digits. e.g. 3107, 5147, 6093, 7125, 8179, 8091, 9101 — look for divisibility pattern
Grid number patterns
Check: row sums, column products, diagonal patterns, or middle = some function of corners
Pie/wheel patterns
Opposite segments, sum of all, product of adjacent — test each hypothesis on known grids first
Topic 14

Spatial / Visual Reasoning

Cube folding
Mark faces systematically. Adjacent in net = adjacent on cube. Opposite faces in a cross-shaped net = top+bottom, left+right, front+back.
Analogy figures
Find the transformation rule: rotation? reflection? element swap? Apply exact same rule to the second pair.
3D shapes
Octahedron: 8 faces, 12 edges → 8+12 = 20. Use Euler: V−E+F=2 to verify.
Topic 15

Game Theory / Strategy

"Say 21" type games
Losing positions repeat every (max+1) numbers. If max add = 3, period = 4. Losing positions: 4, 8, 12, 16, 20. Force opponent to reach these.
Stone removal games
Take 1–3 stones. Losing if pile ≡ 0 (mod 4). With 6 stones: take 2 → leave 4 (losing for opponent). Answer: 2
Card game (sum to 15)
This is isomorphic to tic-tac-toe using a magic square. Second player can always force a draw → "Neither player" wins.
Topic 16

Clock / Circular Motion

LCM for cycles to meet
Lightning +3/stage, Sun −4/stage in 7-segment wheel. They return together after LCM(7/3, 7/4) stages — find when net displacement = 0 mod 7
Faulty clock
Clock loses/gains per hour. Find total drift = gap shown. If gains 1, loses 2 min/hr → gap = 1hr after T hrs → T = 20 hrs from midnight = 20:00
Stopped clock
Stopped 7 hrs ago showing 3:12. Clock lost 12 min/hr for T hours before stopping. Solve: T×12min + 7hrs×12min drift = total lag → find start time
Topic 17

Word / Symbol Coding

Substitution decoding
Find the common element across groups. e.g. Pineapple appears in group 2 and 3. Its meaning is the overlapping output word between both groups.
Systematic approach
Make a table: each fruit → possible meanings. Eliminate by cross-referencing all groups. Only one consistent assignment works.
Topic 18

Investment / Salary Choices

Total earnings over period
Always compute total, not just final value. Monthly salary × months + bonuses vs. compounding quarterly.
Semi-annual raise trick
Option B (raise every 6 months) > Option A (raise every 12 months) even if annual raise looks same — because B gets raise sooner, compounding advantage.
Topic 19

Partnership / Ratio

Profit ∝ Capital × Time
Elon: 1/4 capital × 15 months. Musk: 3/4 capital × T months.
Musk profit share = 2/3, so ratio = 2:1
(3/4)×T / (1/4×15) = 2 → T = 10 months
Fleet capacity
Total = 50×trucks + 1×rickshaws + 10×pickups. Compute for each fleet option.
Topic 20

Balance / Moments (Lever)

Torque = Weight × Distance
Fulcrum divides beam. Sum of (W×d) on left = Sum on right.
Read positions carefully from the diagram.
Brick stack
Each brick = sum of two below it. Work bottom-up: fill in missing values, then add upwards to top.

Speed Calculation Tricks

Multiply by 1.25
× 1.25 = × 5/4. So 24×6×1.25 = 24×6×5/4 = 24×7.5 = 180
Multiply by 75%
× 0.75 = × 3/4. Halve then add half of that.
Square root estimate
√13 ≈ 3.6 (3.5²=12.25, 3.6²=12.96, 3.7²=13.69) → 3.6
√7 ≈ 2.646 → closest = 2.65
a²−b² = (a+b)(a−b)
66×76 − 65×75: not a²−b². Compute directly: 5016 − 4875 = 141
Sum of series
Arithmetic sum = n/2 × (first + last)
10+11+...+14 = 5/2×(10+14) = 60 → but 10+11+9+12+8+13+7+14+6 = 90
a×b + c×d shortcut
4×4+3×3+2×2+1×5 = 16+9+4+5 = 34. Just compute each product first.
